## Rating scale (1–10, aligned with Booking.com)

| Rating | Category | Meaning |
|---|---|---|
| 9–10 | Legend | Top stay, would bring friends, definite return |
| 7–8 | Good | Strong, would consider again |
| 5–6 | Ok | Functional, not memorable |
| 3–4 | Disappointing | Expected more |
| 1–2 | Fail | Would actively warn others |
